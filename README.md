# Ekifu（駅譜）

通勤ルートを楽譜にして、癒し系インストゥルメンタルを端末上で自動生成・再生する Android アプリ。
仕様は [SPEC.md](SPEC.md) を参照。

## 構成

| モジュール | 内容 |
| --- | --- |
| `engine/` | 純 Kotlin の音楽生成エンジン（作曲・合成・エフェクト）。Android に依存しないので PC 上でテスト・試聴できる |
| `app/` | Android アプリ（Jetpack Compose、`AudioTrack` で再生） |

音のパラメータはすべて `engine/src/main/kotlin/jp/fmt/ekifu/engine/MusicConstants.kt` に集約している。

## ビルド

```sh
./gradlew :engine:test          # 作曲ロジック・エンジンの単体テスト
./gradlew :app:assembleDebug    # デバッグ APK（Android SDK が必要）
./gradlew :engine:renderDemoWav # デモ再生を engine/build/demo.wav に書き出す（PC で試聴用）
```

GitHub Actions（`.github/workflows/android.yml`）が push ごとにテストと APK ビルドを行う。
Actions の実行結果ページの「Artifacts」から次をダウンロードできる。

- `ekifu-debug-apk`：スマホに直接インストールできるデバッグ用 APK
- `demo-wav`：デモ再生を書き出した WAV（エンジンの音を PC で確認する用）

## 実機での確認手順

### 段階1：音の再現

完了条件：デモ再生で 3 分の曲が最後まで途切れず鳴り、パッド・プラック・ベル・地下での変化が聞き取れる。

1. GitHub の Actions タブで最新の「Android build」を開き、`ekifu-debug-apk` をダウンロードして解凍する
2. スマホで APK を開いてインストールする（「提供元不明のアプリ」の許可が必要）
3. アプリ「駅譜」を起動し、「デモ 3分」を選んでイヤホンをつけて「デモ再生」を押す
4. 次を順に聞き取る（時刻は再生開始からの実時間）

| 実時間 | 画面の表示 | 聞こえるもの |
| --- | --- | --- |
| 0:00 | 出発・若葉台 | パッドとベースがゆっくり立ち上がる。若葉台のベル（3〜4 音） |
| 0:30 付近 | 桜坂 | 桜坂のベル |
| 0:36 付近 | 道中 | 和音進行が変わり、プラックのメロディが増える |
| 0:49 付近 | 地下を走行中 | 2〜3 秒かけて音がこもり、1 オクターブ下がって、残響が深くなる |
| 道中の 24 拍ごと | — | 直前の駅のモチーフが小さくプラックで鳴る |
| 2:10 付近 | 地上を走行中 | こもりが晴れて元の音域に戻る |
| 2:15 付近 | 到着前 | メロディがやや減り、IV → Vsus → IV → I で締めに向かう |
| 3:00 | 汐見（終点） | 終点のベル（主音 F で終わる） |
| 3:00 すぎ | 到着 | I の和音が長く鳴り、約 12 秒でフェードアウトして止まる |

5. 最後まで途切れ・プチノイズがないこと、「一時停止」「最初から」が効くことを確認する
6. 「デバッグ表示」をオンにすると p・フェーズ・地下フラグを確認できる

### 段階2：バックグラウンド

完了条件：画面オフのまま 30 分間、音切れなしで再生できる。ロック画面から一時停止・再開できる。

仕組み：音は 10 秒単位のチャンクで先に合成し、常に 30〜60 秒ぶんを再生待ちに置く（最初だけ 2 秒のチャンクですぐ鳴らす）。
再生はフォアグラウンドサービス（Media3 の `MediaSessionService`）で行い、通知・ロック画面・イヤホンのボタンから操作できる。

1. 段階1と同じ手順で最新の `ekifu-debug-apk` をインストールする（上書きでよい）
2. アプリを開き「長時間テスト 30分」を選ぶ（同じ 18 分のルートを 30 分かけて進む）
3. 「デモ再生」を押す。初回は通知の許可を求められるので「許可」する（Android 13 以上）
   - ボタンを押してから 1 秒以内に音が出ること
4. 電源ボタンで画面を消し、イヤホンで 30 分聴く。途中で次が聞こえること
   - 5 分ごとに駅のベル（桜坂 5:00、川辺 10:00、中央 15:00、港町 20:00、丘の上 25:00）
   - 約 8:06 に地下に入って音がこもり、約 21:36 に地上に戻る
   - 約 22:30 に到着前、30:00 に終点のベルが鳴り、約 12 秒でフェードアウトして止まる
5. 画面を消したまま、ロック画面の通知（「通勤のサウンドスケープ」「若葉台 → 汐見」）で一時停止・再開する。
   Bluetooth イヤホンの再生/停止ボタンでも操作できること
6. 聴き終わったらアプリを開き、「デバッグ表示」の「バッファ不足 = 0 回」を確認する。
   PC につないでいれば `adb logcat -s Ekifu` に「バッファ不足」が 1 行も出ていないことでも確認できる
   （バッファ残量は通常 30〜60 秒の間で推移する）

補足：段階2ではオーディオフォーカス（着信・他アプリの再生）とイヤホンが抜けたときの一時停止はまだ入っていない（段階5で対応）。
